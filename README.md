Makine öğrenmesi projem. Text to Text and Embedding
BTK akademi sıfırdan ileri düzey makine öğrenmesi programında  Çanakkale Onsekizmart Üniversitesinde ekip arkadaşım Tolunay Nehirle beraber yapmış olduğum text to text embedding çevirici projemiz %95'lik başarı oranına sahiptir. Bu projenin amacı excelde metin formatındaki verileri farklı dillere( İspanyolca, Fransızca, İngilizce) çevirmektir. Amacımız makine öğrenmesinin temelini kavrayıp sıfırdan bir mobil uygulama yapmaktır. Modelimiz doğru çalışsa da henüz mobil uygulama kısmına geçmedik. Bu projede temel amaç makine öğrenmesinin temelini kavrayıp sıfırdan ileri düzey seviyesine gelmektir.
